# Iteration 008

## Prompt

- Build and publish a new GitHub Pages course that introduces geometry using Omri's observed mission-driven learning process.

## Learning Design

- Frame the course as building a game arena rather than reading definitions.
- Focus the first course on point, segment, ray, and line to keep the intrinsic load manageable.
- Open with a concrete placement task and a meaningful success within minutes.
- Use the loop mission → observation → prediction → action → evidence → explanation → transfer.
- Present one primary action at a time, keep the current evidence visible, and offer a graduated hint ladder.
- Fade support from a demonstrated action to independent classification and explanation.
- Verify understanding in a new context: a city map rather than the original game arena.

## Output

- Added `geometry-arena/` as a responsive static HTML/CSS/JS course.
- Added six progressively unlocked interactive missions and immediate evidence-based feedback.
- Added a persistent investigation board, adaptive hints, a transfer task, and an exit ticket.
- Added the course to the public `edu` index with source and process links.
