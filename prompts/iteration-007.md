# Iteration 007

## Prompt

- Integrate the educational analysis of Omri's real-world Roblox troubleshooting conversation into the shared lesson-builder skill.

## Observed Design Needs

- Anchor learning in an authentic desired outcome.
- Use concrete visible states, short actions, and immediate evidence.
- Reduce unnecessary language and navigation load without removing reasoning.
- Convert requests for confirmation into prediction, explanation, and transfer.
- Fade support from demonstrated steps to independent planning.
- Add explicit safety gates for consequential computer actions.

## Output

- Added an explicit working learner profile for Omri to the shared skill.
- Added a mission → observation → prediction → action → evidence → explanation → transfer loop.
- Added cognitive-load constraints, a four-level scaffolding progression, safety gates, and transfer-based mastery checks.
- Updated the active lesson-builder prompt so future lesson implementations apply these principles.
